# Portfolio of Mohamed Abbas KONATE

This repository contains the source code for my online resume. I have configured the structure to use a local `assets/` folder.

## File Structure
- `index.html`: The main page.
- `assets/`: The folder where you should place your media files.

## How to finalize before pushing to GitHub

1. **The Video**: 
   - Place your video file in the `assets/` folder.
   - Rename your video to `my_video.mp4` **OR** open `index.html` and modify the line `<source src="./assets/my_video.mp4" type="video/mp4">` with the exact name of your file.
2. **The PDF**: 
   - Replace the `assets/Resume_Mohamed_Abbas_KONATE.pdf` file (the placeholder) with your actual PDF file.
3. **Push everything to the `main` branch** and enable GitHub Pages in the repository settings.
